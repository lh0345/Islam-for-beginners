# Content and experience audit

Reviewed 2026-09-11 against the existing workspace catalog: 84 lessons, 140 questions, their feedback, reflection, and review fields. All lesson prose and review notes were rewritten. All 140 old question IDs are retired; 56 newly authored prompts use a separate identity namespace. The original day/lesson identities remain for progress compatibility.

The new model is a continuous guided reading with an optional 3–6-section view. Sections are selected for the argument: opening, explanation, lived example, distinction, or reflection. No role except an intelligible beginning is mandatory. There is no forced four-screen pattern. Each day has two prompts, with open consideration and connections making up the majority. Explanations stay open, and all continuation is explicit. Review is a readable collection, with persistent kept/revisit choices and no mastery claim.

The per-item decisions below assess beginner value, connection to surrounding ideas, memory-only demands, templated voice, and religious qualification. New lessons retain thematic continuity but do not reuse the old field template. The IDs in the questions table are editorial traceability, not migration aliases: an old correct answer never marks a new prompt considered.

## Persistence

Version 2 reads version 1 only if no version 2 save exists and writes to a separate key. The original save is retained. Completed lesson/day IDs and activity are preserved; obsolete points, quiz mastery, misses, and queues are not treated as new learning. Current prompt completion, review choices, and review timestamps persist. Storage writes are ordered; read or parse failure opens a retry screen before saving. A reading is marked read only by its ending action. There is no page-offset bookmark: leaving an unfinished exploration reopens that exploration from its beginning.
